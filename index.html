NFL Spoiler-Free Data

Static, season-scoped game data published from the public nflverse releases. CSV files retain the source columns and values, including every game type and nullable scores.

Browse the data manifest for current season files, SHA-256 hashes, source release metadata, and record counts.

Data attribution: nflverse-data contributors, nflverse-data, licensed under CC BY 4.0. This site filters the source data into per-season files.
